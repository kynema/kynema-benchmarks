Immersed boundary
=================

The immersed-boundary cases evaluate channel walls represented with
``ChannelBuilder`` immersed boundaries and the ``DragForcing`` wall model.

#. `Laminar channel flow <immersed_boundary/laminar_channel_flow/README.html>`__:
   Spatial convergence of pressure-driven Poiseuille flow in flat and
   45-degree immersed-boundary channels, with a no-immersed-boundary
   reference study.

   * `Setup and execution <immersed_boundary/laminar_channel_flow/README.html#generate-solver-inputs>`__
   * `Convergence analysis <immersed_boundary/laminar_channel_flow/README.html#analyze-convergence>`__
   * `Results <immersed_boundary/laminar_channel_flow/README.html#outputs>`__

#. `Turbulent channel flow <immersed_boundary/turbulent_channel_flow/README.html>`__:
   Wall-resolved LES of turbulent channel flow at :math:`Re_\tau = 180` and
   :math:`Re_\tau = 395`, compared with DNS data.

   * `Setup and execution <immersed_boundary/turbulent_channel_flow/README.html#run-the-solver>`__
   * `Statistics analysis <immersed_boundary/turbulent_channel_flow/README.html#analyze-statistics>`__
   * `Results <immersed_boundary/turbulent_channel_flow/README.html#results>`__

`View these cases in the GitHub repository
<https://github.com/Kynema/kynema-benchmarks/tree/main/kynema-sgf/immersed_boundary>`__
